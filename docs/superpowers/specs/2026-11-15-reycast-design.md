# ReyCast — design

A Raycast-style app launcher for Alfonso's Galaxy Tab S8 Ultra, summoned with **Cmd+Space**.

## Context

- Tablet: Galaxy Tab S8 Ultra (SM-X900), One UI 8 / Android 16, used in DeX (Android 16 desktop
  windowing) with a Bluetooth Corne keyboard. No root.
- Key Mapper 4.7.0 runs in Expert mode and detects the Corne's raw keys (evdev triggers). Its remaps
  are generated by `~/Documents/gen_evdev.py` and imported from `/sdcard/Download/mac-shortcuts.json`.
  The Corne's Cmd key is Left or Right Meta depending on the hand (home-row mods); Android remaps
  Meta → Alt system-wide, so only raw-key triggers can tell Cmd apart from Alt.
- The Mac has adb access to the tablet and will build and install the app.

## Goal

Launch any installed app from the keyboard in a few keystrokes: Cmd+Space, type a few letters,
Enter. The only feature is app launching.

Out of scope: commands, scripts, plugins, window management (already done in Key Mapper),
calculator, web search, snippets, clipboard history, settings screen, themes, start at boot.

## User experience

- **Summon:** Cmd+Space opens a floating search box in the upper middle of the screen
  (Raycast/Spotlight style). The desktop stays visible around it. Pressing Cmd+Space while it is open
  closes it.
- **Empty box:** shows the 8 most-used apps (ranked by usage history). With no history, it shows the
  first 8 apps alphabetically.
- **Typing:** filters the list on every keystroke. Apps that don't match are hidden. The top result
  is always highlighted.
- **Keys:**
  - ↑ or Ctrl+K moves the highlight up; ↓ or Ctrl+J moves it down. The highlight stops at the first
    and last row (no wrap-around).
  - Enter launches the highlighted app and closes ReyCast. With no results, Enter does nothing.
  - Esc closes ReyCast.
- **Closing:** ReyCast also closes when it loses focus (click or tap outside, Cmd+Tab, another
  window opening).
- **Look:** dark rounded panel, search field on top, result rows below with app icon and name; the
  highlighted row has a blue background. At most 8 rows are visible.
- ReyCast never appears in Recents / the app switcher.

## Ranking

Each app gets a match tier against the query, then is ordered by usage within the tier.

Matching is case-insensitive and accent-insensitive (labels and query are normalized to lowercase
ASCII by stripping diacritics before comparing).

Match tiers, best first:
1. **Prefix:** the label starts with the query ("te" → Termux).
2. **Word start:** a word inside the label starts with the query ("store" → Play Store). Words are
   split on spaces, `-`, `_`, `.` and lowercase→uppercase boundaries in the original label.
3. **Subsequence:** the query's characters appear in order in the label ("tmx" → Termux). Within this
   tier, matches with fewer gaps between characters rank higher.
4. No match: the app is hidden.

Within a tier, apps are ordered by **frecency**, then alphabetically:
- Each launch through ReyCast is recorded with its timestamp. Only the 20 most recent launches per
  app are kept.
- Each kept launch contributes points by age: under 4 hours 100, under 1 day 80, under 3 days 60,
  under 1 week 40, under 30 days 20, older 10.
- An app's frecency is the sum of its launches' points.

The empty-box list uses frecency alone.

## Architecture

A single-activity Kotlin app, package `dev.victorstein.reycast`, label "ReyCast", built with plain
Android Views (no Jetpack Compose) to keep the APK small and the window fast to appear.

Components:

| Unit | Responsibility | Depends on |
|------|----------------|------------|
| `LauncherActivity` | The floating window: search field, result list, key handling, launch, close-on-focus-loss, toggle on re-summon. | `AppCatalog`, `Ranker`, `UsageStore` |
| `AppCatalog` | Lists launchable apps (`ACTION_MAIN` + `CATEGORY_LAUNCHER`) via `PackageManager` each time the window opens, excluding ReyCast itself; loads icons lazily. | Android `PackageManager` |
| `Matcher` | Pure function: (query, label) → match tier and gap score, or no match. | nothing |
| `UsageStore` | Records launches and computes frecency; persists to a small JSON file in app-private storage. | a clock, a file |
| `Ranker` | Pure function: apps + query + frecency scores → ordered list (max 8). | `Matcher` |

`Matcher` and `Ranker` are plain Kotlin with no Android dependencies so they can be unit-tested on
the Mac. `UsageStore` takes its clock and file as constructor parameters for the same reason.

### Window

- Translucent activity themed as a floating panel, `launchMode="singleTask"`,
  `excludeFromRecents="true"`, no animation on open/close.
- Positioned horizontally centered on the current display, 40% of the screen width, its top edge at
  15% of the screen height.
- `onNewIntent` while visible (Cmd+Space again) finishes the activity.
- `onPause` / window focus loss finishes the activity.
- The search field takes focus immediately. The soft keyboard does not appear when the Corne is
  connected (the tablet already hides it with a hardware keyboard).

### Launching

- Enter calls `startActivity` with the app's launch intent (`FLAG_ACTIVITY_NEW_TASK`). If the app is
  already running, Android brings its existing task forward instead of opening a second window.
- The launch is recorded in `UsageStore` before ReyCast finishes.

### Package visibility

Android 11+ hides other apps by default. The manifest declares a `<queries>` entry for
`ACTION_MAIN` + `CATEGORY_LAUNCHER` intents so `AppCatalog` can see every launchable app.

## Hotkey

`gen_evdev.py` gains one map per Cmd key (Left Meta and Right Meta, both `DO_NOT_CONSUME`) + Space,
raw Corne triggers, action **APP** with package `dev.victorstein.reycast`, no app constraints (works
everywhere, including Termux and herdr). The regenerated `mac-shortcuts.json` is imported with
Restore → Replace.

## Error handling

- **App uninstalled after the list was built:** Enter shows a short toast ("App not found"), removes
  the row, and keeps ReyCast open.
- **Usage file unreadable or corrupt:** treated as empty history; the next launch rewrites it.
- **Icon fails to load:** a neutral placeholder icon is shown; the row still works.
- **Key Mapper not running:** Cmd+Space does nothing; ReyCast remains openable from the app drawer and
  behaves the same once open.

## Build and install

- Toolchain on the Mac via Homebrew: a Java 21 JDK and Android command-line tools (SDK platform for
  Android 16 / API 36, matching build-tools). Gradle wrapper in the repo.
- `minSdk` 36 / `targetSdk` 36: the app only targets this tablet.
- Debug-signed APK installed with `adb install -r`, so updates keep the usage history.
- Project: `/Volumes/stein/Documents/development/personal/android-launcher`, local git repo.

## Testing

- **Unit tests (JVM, written first):**
  - `Matcher`: prefix, word start (including camelCase and `Play Store`), subsequence with gap
    ordering, no match, case and accent insensitivity, empty query.
  - `UsageStore`: point buckets at each age boundary, 20-launch cap, corrupt-file recovery.
  - `Ranker`: tier beats frecency, frecency orders within a tier, alphabetical tiebreak, 8-row cap,
    empty query uses frecency then alphabetical.
- **On-device checks over adb:**
  - `am start -W` on the activity: window displayed in under 200 ms when the app process is warm.
  - Type with `input text`, then confirm the expected top row via `uiautomator dump`.
  - Enter launches the highlighted app; Esc and focus loss close ReyCast.
- **Manual:** Cmd+Space from Chrome, Termux and an empty desktop; launch an already-running app and
  confirm its existing window comes forward.
